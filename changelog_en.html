Version 1.26.7.3101 Release Notes

  • New Features:
  • 1. Motion Control: Added multi-segment position and multi-segment velocity control.
  • 2. JOG: Added walking JOG.
  • 3. Oscilloscope: Added horizontal cursor for the Y-axis.
  • 4. Auto-tuning: Added walking parameter identification.
  • 5. Others: Support for Modbus protocol, one-click installation, and online software update.
  • Bug Fixes:
  • 1. Alarm Notification: Optimized alarm display logic to always show the latest alarm.
  • 2. Parameter List: Extended the display duration of the read/write reminder popup.
  • 3. Boot: Restricted firmware flashing to .bin files only.
